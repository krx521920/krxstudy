# SQL 订单实战：样例数据与练习

> [!summary] 一句话解释
> 用一份可手算的小商店订单数据，练习查询、关联、统计、窗口、清洗、约束、索引与回滚，并把实际结果与预期对照。

入口：[[SQL与关系型数据库学习地图]]。把这份数据看成迷你账本：先看懂每条记录，再逐步汇总，不用一开始安装复杂数据库服务器。

## 配套文件与安全范围

- 建表与数据：[订单样例.sql](SQL练习/订单样例.sql)。只在**全新、空的练习库**加载一次。
- 自动校验：[校验SQL示例.py](SQL练习/校验SQL示例.py)。使用 Python 自带 sqlite3 模块，无需额外安装库。

脚本只连接 `:memory:` 内存数据库，不连接网络、不写数据库文件、不修改原有笔记。每个标注示例都在重新建立的样例上运行，修改库存的练习不会影响其他题。

脚本会直接读取同目录专题笔记中的 `sql` 代码块及 `-- lab: 名称` 标记，不是另抄一套相似 SQL 来冒充验证。未标记的方言、表达式片段与伪代码不算已实测。

## 如何运行自动校验

在仓库根目录 `D:\krxstudy` 的终端运行：

```powershell
python "03-Web后端与数据库/SQL练习/校验SQL示例.py"
```

它会输出 SQLite 实际版本，以及查询、约束、事务和链接校验结果。要求 Python 所带 SQLite 支持窗口函数；若工具不存在，这个命令不会自动安装软件。

本次核对环境：SQLite 3.51.0。验证范围是本机 SQLite 的公共例子，不表示已验证 MySQL/PostgreSQL 方言、两连接锁竞争、崩溃恢复或主从复制。

## 手动交互练习

如果电脑已有 sqlite3 命令，可以从仓库根目录启动一个新的内存库：

```powershell
sqlite3 :memory:
```

进入 SQLite 提示符后再输入：

```text
.bail on
.headers on
.mode column
PRAGMA foreign_keys = ON;
.read "03-Web后端与数据库/SQL练习/订单样例.sql"
```

这些点开头的命令是 SQLite 命令行指令，不是 SQL，不要贴进其他数据库。加载后可复制笔记中的完整 SELECT；退出内存库后数据消失，下一次重新加载即可。

不要反复在同一个已加载库执行建表脚本，它会因表已存在报错。我们不使用自动 DROP 清表，避免你误选数据库时把原有内容删掉。
