# 存储层次：RAM、SRAM、DRAM、Cache 与 Flash

> [!summary] 一句话解释
> 存储层次用“小而快”和“大而便宜”的多种存储配合工作；RAM/ROM、SRAM/DRAM/Flash、Cache/主内存/显存分别强调不同分类维度，不能全部当成互斥同义词。

像书桌和仓库：手边的小便签取用最快，桌面能放更多资料，书柜能放更多，远处仓库容量更大。实际系统中的“快”还有延迟、带宽和并发等维度，不能只看距离类比。

## “内存”和“硬盘”先分清

日常电脑配置中的内存通常指系统主内存，用来保存程序运行时正在使用的代码和数据；硬盘负责长期保存程序、文档和模型文件。

例如“32 GB 内存＋1 TB 硬盘”，是两种用途的容量，不能简单合成“1032 GB 运行内存”。这里 GB 是 Gigabyte（吉字节），TB 是 Terabyte（太字节）；显示软件也可能采用二进制容量单位，需看实际口径。

操作系统加载程序时可以按需建立映射并读取页面，不要求把所有文件一次性完整复制进物理内存。详情见 [[内存映射、MMIO与代码控制硬件]]。

## RAM 的随机是什么意思

**RAM = Random-Access Memory（随机存取存储器，读 RAM）**。随机访问指能按地址访问位置，不必像磁带一样顺序经过所有前项；不是随机挑一条数据，也不是数据乱存就无需组织。

访问时间不必在现实硬件中完全相等：缓存、DRAM 行状态和并发请求都会影响延迟。“随机存取”主要描述访问方式。

日常 RAM 通常指可读写、断电丢失的工作存储。但“能随机访问”与“是否非易失”在概念上是不同维度，不应说所有能随机访问的存储都必然断电丢失。

## SRAM 与 DRAM：都常用作易失性工作存储

**SRAM = Static Random-Access Memory（静态随机存取存储器，读 S-RAM）**。

典型 SRAM 单元用晶体管组成稳定状态电路，在正常持续供电条件下不需要像 DRAM 那样周期性刷新。它通常快、单位容量占芯片面积较大，常用于处理器缓存和片上小容量存储。

**DRAM = Dynamic Random-Access Memory（动态随机存取存储器，读 D-RAM）**。

典型 DRAM 单元利用电容电荷表示状态；电荷会泄漏，因此需要刷新维持。它通常密度更高、每位成本更低，适合较大容量主内存，也用于很多显存技术。

| 对比 | SRAM | DRAM |
|---|---|---|
| 典型保存方式 | 稳态电路状态 | 电容电荷状态 |
| 正常供电下是否需要周期刷新 | 通常不需要 | 需要 |
| 断电后是否通常保留 | 不保留 | 不保留 |
| 常见优势 | 低延迟、适合片上访问 | 高密度、较低单位容量成本 |
| 常见位置 | CPU/GPU 缓存、片上工作区 | 系统主内存、很多 GPU 设备内存 |

**静态不等于永久保存；动态不等于容量会自动变化。** 不能把 SRAM 当成不怕断电的硬盘。带电池备份等特殊系统可以改变系统级保留能力，但不改变普通 SRAM 单元本身的易失性。

## DDR、GDDR 和 HBM 放在哪里理解

**DDR = Double Data Rate（双倍数据速率，读 D-D-R）**，这里指常见同步 DRAM 技术家族中的数据传输方式；不是“内存容量双倍”。

**GDDR = Graphics Double Data Rate（图形双倍数据速率，读 G-D-D-R）**、**HBM = High Bandwidth Memory（高带宽内存，读 H-B-M）** 是面向图形/加速计算等高带宽需求的 DRAM 技术与组织方式。

**VRAM = Video Random-Access Memory（视频随机存取存储器，显存，读 V-RAM）** 说明用途。现代显存常基于 DRAM，而不是一种和 DRAM 完全互斥的物理类别。详见 [[GPU、显存与CUDA并行计算]]。

DDR 的不同代际、容量和频率不能仅看外形互换；实际兼容要由处理器、主板和模块规范共同确认，本篇不做具体购买或插装建议。

## Cache 是什么：一种“留在近处方便再用”的角色

**Cache（缓存，读作 cash，近似“凯什”）** 保存近期或附近可能再次使用的数据/指令，使重复访问不必每次去较慢层取。

两种常见局部性：

- 时间局部性：刚用过的变量、指令，可能很快再用。
- 空间局部性：刚访问数组某项，接下来可能访问附近项。

CPU Cache 常按 Cache Line（缓存行）搬运一定大小的数据块，不是只缓存程序眼前那一个字节。实际缓存行大小和策略看架构。

Hit（命中）表示该次查询能在相应缓存找到可用数据；Miss（未命中）则需要继续取数。缓存容量、布局、访问顺序和其他核心活动都会影响命中情况。

## L1、L2、L3 与寄存器

L 代表 Level（层级）。通常 L1 小而近，L2 更大，L3 可能更大并由多个核心共享，但不能把这个常见模式当作所有处理器的统一布局。

寄存器是指令直接使用的少量处理器状态；硬件 Cache 通常由硬件依据地址和策略管理。二者都很快，但不是同一层东西。

```text
常见 CPU 数据访问层次（概念示意）
寄存器 ←→ 处理器 Cache（L1/L2/可能的 L3）←→ 系统主内存
                                                    ↑
                               按需从硬盘等持久存储读取
```

缓存与主内存可以存在多份相关副本，硬件一致性和软件同步共同保证正确使用；有缓存一致性不等于多线程程序自动没有竞争。

CPU Cache 通常由 SRAM 实现；操作系统文件缓存则常占用 DRAM；浏览器磁盘缓存可能落在 SSD。**Cache 是角色，不是一种固定存储材料。** AI 中的 KV Cache 又是保存模型中间结果的算法概念，不等于 CPU 的 L1/L2。

## ROM 是什么，为什么“刷 ROM”又好像能写

**ROM = Read-Only Memory（只读存储器，读 ROM）**。严格的掩膜 ROM 在制造时固化内容，不能像 RAM 一样随意修改，断电仍保留数据。

历史上有多种可编程或可擦写的非易失性存储：

- PROM：Programmable Read-Only Memory（可编程只读存储器），常见一次性编程语境。
- EPROM：Erasable Programmable Read-Only Memory（可擦除可编程只读存储器），经典实现通过紫外线擦除。
- EEPROM：Electrically Erasable Programmable Read-Only Memory（电可擦除可编程只读存储器）。

这些缩写可分别按 P-ROM、E-P-ROM、E-E-P-ROM 辨认。工程口语里的“ROM 镜像”“刷 ROM”还可能指固件/系统镜像及其更新，而不表示真的改写物理掩膜 ROM。

手机宣传里的“256 GB ROM”常把可写的内部 Flash 存储俗称 ROM，不宜把这种营销口径搬成教材里的严格定义。

## Flash 是什么

**Flash Memory（闪存，通常简称 Flash，读 flash）** 是可电擦写、断电通常保留数据的半导体存储。典型技术利用浮栅或电荷俘获等机制改变单元状态，与 DRAM 靠持续刷新保留电容电荷不同。

Flash 常按块擦除，再按规定单位编程；不是每次修改一个字节都能像 RAM 一样随意原地覆盖。擦写寿命、保留时间和错误处理也需要管理。

| 常见类型 | 常见倾向 | 典型应用 |
|---|---|---|
| NOR Flash | 适合代码存储与相应随机读取/执行场景 | 平台或设备固件、嵌入式程序 |
| NAND Flash | 适合高密度大容量存储 | SSD、手机存储、存储卡等 |

NOR、NAND 是与电路组织相关的逻辑名称，不是操作系统。具体访问方式还由接口和控制器决定，不能只凭类型推断所有性能。

Flash 与 ROM 不能简单归为“一个能写、一个完全不相关”：Flash 属于可擦写非易失性技术，经常承担传统 ROM 的固件存储角色。内容和存储介质仍要分开，见 [[固件、ROM代码与计算机启动链]]。

## 硬盘、SSD、Flash 的关系

**HDD = Hard Disk Drive（硬盘驱动器，通常指机械硬盘，读 H-D-D）** 使用磁性介质和机械机构。

**SSD = Solid-State Drive（固态硬盘，读 S-S-D）** 是完整存储设备，常包含 NAND Flash、控制器、固件等，部分还带 DRAM。不是“一颗 Flash 裸芯片接线就等于可直接用的硬盘”。

主板固件可能存于小容量 NOR Flash，SSD 的大量文件可能存在 NAND Flash；两者都用 Flash，但容量、接口、管理和用途不同。

完整设备和接口见 [[磁盘与网卡：存储设备和网络接口]]，不在这里重复全部磁盘选型知识。

## 一张对照表：角色、技术与断电

| 常见对象 | 主要作用 | 常见实现 | 一般断电后 |
|---|---|---|---|
| CPU Cache | 加速重复与邻近访问 | SRAM | 丢失 |
| 系统主内存 | 程序运行工作区 | DRAM | 丢失 |
| 独立 GPU 专用显存 | 图形/计算工作数据 | GDDR/HBM 等 DRAM | 丢失 |
| 不可变 Boot ROM | 最早启动代码 | 掩膜 ROM 等 | 保留 |
| 主板可更新固件存储 | 保存平台固件等 | 常见 NOR Flash | 保留 |
| 固态硬盘 | 长期文件存储 | NAND Flash＋控制器等 | 通常保留已可靠写入数据 |
| 机械硬盘 | 长期文件存储 | 磁性介质＋机构/控制器 | 通常保留已可靠写入数据 |

“非易失”不等于永不损坏、永久无需备份，也不保证尚在易失缓存中的写入已经落盘。

## 虚拟内存不是凭空增加物理 RAM

操作系统为进程提供虚拟地址空间，并把地址映射到物理内存、文件或其他后备机制。换页可能用硬盘暂存部分数据，但访问速度与物理 RAM 不同。

“内存不够就用硬盘顶上”可能避免部分分配失败，也可能导致严重等待；它不是免费扩容，独立 GPU 的显存不足也不必然能无损自动转移。

## 学习建议与常见误区

先问三个问题：这是“用途角色”还是“实现技术”？断电通常保留吗？谁在访问、需要多快和多大？

重点纠正：SRAM 的 S 不是 Save；DRAM 的刷新不等于屏幕刷新率；Cache 不等于永久文件；ROM/Flash 不等于 BIOS/UEFI 软件本身；硬盘容量大不等于运行内存足够。
