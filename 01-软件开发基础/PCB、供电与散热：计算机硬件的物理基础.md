# PCB、供电与散热：计算机硬件的物理基础

> [!summary] 一句话解释
> 电路板把元件连接成系统，供电电路把输入电能转换成芯片需要的稳定电压和电流，散热系统把工作产生的热量移走；三者共同决定硬件能否稳定发挥性能。

像一栋楼：板上走线是连接路线，供电是配电系统，散热是把热量送出楼外的设施。再强的计算芯片，也不能脱离这些物理条件工作。

入口：[[计算机硬件与底层软件学习地图]]。

## PCB 不是处理器，而是连接基础

**PCB = Printed Circuit Board（印刷电路板，读 P-C-B）**。常见组成包括绝缘基材、铜导体层、焊盘、连接不同层的过孔、阻焊层和标记文字。

“印刷”是历史名称，不代表现代高密度板像普通纸张一样打印即完成。多层 PCB 内部也有信号、电源和接地层，并不只有表面看得到的线路。

裸板与焊好元件的板卡不同。**PCBA = Printed Circuit Board Assembly（印刷电路板组装件，读 P-C-B-A）**，通常指安装焊接元件后的板级组件。

主板、显卡和很多固态硬盘都有 PCB。显卡板上通常还有计算芯片、显存、供电电路、连接器和固件存储等；所以 GPU 芯片不等于完整显卡。

## PCB 上的信号为什么不是理想的“零成本导线”

高速信号存在传播延迟、反射、串扰和噪声；电源线路也存在电阻与寄生电感。布局、走线、接地与回流路径、层叠和去耦都影响稳定性。

不能只凭“层数越多越好”“走线越粗越好”评价设计。不同信号需要不同约束，PCB 是工程设计，不只是把端点随意连起来。

## 电源与板上供电不是一回事

台式机的 **PSU = Power Supply Unit（电源供应单元，读 P-S-U）** 把输入电能转换成若干直流输出。板卡继续把输入转换成处理器核心、显存等不同电压轨需要的电源。

**VRM = Voltage Regulator Module（电压调节模块，读 V-R-M）**，这里指围绕处理器等负载工作的稳压供电功能模块，不要求一定是可拆下来的独立小板。

**VRAM 是显存，VRM 是供电。** 两者名称相近，但不是同一种元件。

## 供电元件各自做什么

| 元件/模块 | 通俗作用 | 边界 |
|---|---|---|
| 电源控制器 | 观察输出并调节开关动作 | 不直接等于全部供电电路 |
| MOSFET | 高速开关，控制电能流动 | 工作会有损耗，不是理想无损开关 |
| 电感 | 在开关周期中储存和释放磁场能量，使电流变化更平滑 | 不只是一小块“实心金属” |
| 电容 | 局部储能、滤波、缓冲快速负载变化 | 电解、陶瓷等类型用途与特性不同 |
| 电阻与采样电路 | 反馈、限流、检测等 | 小元件也可能影响稳定性 |
| 保护电路 | 处理过流、过压、过温等异常 | 保护机制不能替代正确使用 |

**MOSFET = Metal-Oxide-Semiconductor Field-Effect Transistor（金属氧化物半导体场效应晶体管，常读作 MOS-fet）**。名称描述器件类别；初学先理解它可以受控制地导通或关断。

**PWM = Pulse-Width Modulation（脉宽调制，读 P-W-M）** 是调节开关脉冲占比的一种常用方法。现代电源控制方式有多种，不是所有芯片都只有一种简单 PWM 策略。

降压转换器常称 Buck Converter。多相供电让多个功率通道交错工作，有助于分担电流与改善输出波动，但不能仅凭宣传的相数判断优劣；器件能力、控制、布局和散热都重要。[TI 处理器多相供电](https://www.ti.com/product-category/power-management/multiphase.html)

## 电压、电流与功率

用简单直流近似理解：

$$
P=VI
$$

P 为功率，单位瓦 W；V 为电压，单位伏 V；I 为电流，单位安 A。

假设某核心电压轨输出 1 V、100 A，输出功率约 100 W。若转换效率假设为 90%，输入约需 111 W，转换过程约损耗 11 W。这里只是解释用的数值，不是你电脑的实测参数，也不等于整个处理器或整张显卡只有这一条电源轨。

电源标称可供 750 W，不等于整机随时消耗 750 W；实际负载在能力范围内取电。额定能力、瞬时负载、转换损耗与电费应分开理解。

## 为什么计算会发热

晶体管切换、充放电和漏电等会消耗能量，实际电子系统中大量消耗最终表现为热。提高频率和电压可能增加功耗，但具体关系依电路、负载与控制策略而异。

芯片在安全边界内运行时，也可能因温度、功率或电流限制降低频率。Thermal Throttling（热降频）是一种保护和温度控制机制，不是程序突然不认识指令了。[Intel 热降频说明](https://www.intel.com/content/www/us/en/support/articles/000088048/processors.html)

## 散热链条：热量必须真正到外界

```mermaid
flowchart LR
    Chip["芯片产生热"] --> Interface["封装与导热接触界面"]
    Interface --> Base["散热器底座"]
    Base --> Transport["热管 / 均热板 / 冷却液"]
    Transport --> Fins["鳍片或冷排"]
    Fins --> Air["空气与环境"]
```

实际结构可能省略或组合其中环节。风扇帮助空气流动，热管/均热板帮助搬运和扩散热量，导热材料填补接触微小间隙；它们不是把热“消灭”。

普通风冷或水冷并非冰箱，不能在稳定工作时无条件把持续发热芯片降到环境温度以下。水冷也要把冷却液中的热量交给环境。

**TIM = Thermal Interface Material（导热界面材料，读 T-I-M）** 包括适用位置的导热膏、导热垫等。不是越厚越好，错误厚度或材料可能影响接触和电气安全。

## 供电、散热和性能怎样配合

- 算力强但供电不稳定：可能报错、重启或触发保护。
- 算力强但持续散热不足：可能无法长期保持高频。
- 显存容量充足但带宽不够：计算单元可能等待数据，见 [[GPU、显存与CUDA并行计算]]。
- 温度不高却速度慢：也可能是程序、内存、磁盘、功率策略等瓶颈，不应只怪散热。

不能靠一个温度读数诊断全部问题；传感器位置、环境温度、负载与厂商限制都需要对应。

## 初学者安全边界

认识元件不等于适合自行维修。不要拆开市电电源外壳：断电后电容也可能残留危险电压。不要用金属工具随意短接板上元件，也不要为验证笔记去刷固件、加电压或关闭保护。

若只是学习，先看官方板卡框图或清晰照片，识别连接器、芯片、存储颗粒、供电区域和散热路径；操作实物要按设备说明和专业安全条件进行。

操作系统里的 PCB 另指进程控制块，是软件数据结构，见 [[操作系统、内核与硬件管理]]，不要与印刷电路板混淆。
