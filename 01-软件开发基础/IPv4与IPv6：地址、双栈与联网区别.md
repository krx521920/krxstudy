# IPv4与IPv6：地址、双栈与联网区别

## 一句话解释

**IPv4 和 IPv6 都是互联网协议，IPv6 最显著的变化是把地址从 32 位扩大到 128 位；它还改变了一些网络工作机制，但不等于自动更快、更安全，或能直接兼容所有 IPv4 服务。**

- IP = **Internet Protocol，互联网协议**，逐字母读 I-P，负责网络层的寻址与数据包转发规则。
- IPv4 = **Internet Protocol version 4，互联网协议第 4 版**，可读“I-P-V 四”。
- IPv6 = **Internet Protocol version 6，互联网协议第 6 版**，可读“I-P-V 六”。

它们不只是两种地址写法，数据包格式与部分处理规则也不同。版本号 4、6 不是网速档位、地址位数，也不是移动网络的代际。

## 一、先用门牌号理解 IP 地址

快递需要地址，网络数据包也需要来源地址与目的地址，路由器根据路由规则把包逐步转发。

可以先把 IP 地址理解为“网络中的门牌号”。更准确地说，地址通常配置在网络接口上：同一台电脑的有线网卡、无线网卡、虚拟网卡可以拥有不同地址，同一个接口也可能同时有多个地址。

地址不是设备终身不变的身份证，也不直接等于人的真实身份；换网络、重新分配地址或使用临时地址后，都可能发生变化。

生活类比：IPv4 像较早设计、号码容量有限的门牌系统；IPv6 像容量大幅扩充的新系统。但现实中的两种协议并不是“给旧号码前面补几个数字”就能互通。

## 二、核心区别表

| 比较项 | IPv4 | IPv6 |
|---|---|---|
| 地址长度 | 32 个二进制位 | 128 个二进制位 |
| 理论地址组合数 | `2^32`，约 42.95 亿 | `2^128`，约 `3.4 × 10^38` |
| 常见写法 | 四组十进制数字，用点分隔 | 八组十六进制数，用冒号分隔，可按规则缩写 |
| 文档示例 | `192.0.2.10` | `2001:db8::10` |
| 家庭上网常见方式 | 内网设备经地址和端口转换，共用公网出口地址 | 可为设备分配全局地址，通常无需为节省地址而共享一个出口地址 |
| 地址配置 | 可以自动分配，也可以手工配置 | 同样支持自动和手工配置，还支持无状态地址自动配置 |
| 相互兼容 | 仅 IPv4 的端点不能直接处理原生 IPv6 通信 | 仅 IPv6 的端点也不会天然直接访问所有 IPv4 服务 |

bit（二进制位，读作“比特”）只有 0、1 两种取值，因此地址长度增加会让组合数按指数增加。128 位是 32 位的 4 倍，但地址数量不是仅增加到 4 倍。

上表是理论组合数；其中存在保留地址和特殊用途范围，不能把所有组合都当作可随意分配的公网地址。[IPv6 规范中的地址扩展说明](https://www.rfc-editor.org/rfc/rfc8200)

## 三、两种地址分别怎么看

### IPv4：点分十进制

例如 `192.168.1.20`，有四组数字，每组通常写成 0～255 的十进制数。

家中电脑可能是 `192.168.1.20`，手机是 `192.168.1.30`，路由器是 `192.168.1.1`。这些是私有地址示例，不是公网地址；不同家庭可以重复使用这些地址，因为它们位于不同的网络范围。

`127.0.0.1` 是常用的本机回环地址：访问它表示访问自己，而不是访问别人的电脑。

### IPv6：冒号分组的十六进制

完整示例：

```text
2001:0db8:0000:0000:0000:0000:0000:0010
```

可以缩写成：

```text
2001:db8::10
```

十六进制用 `0～9` 和 `a～f` 表示数字。每组前导零可以省略，一段连续的全零组可以用 `::` 表示；同一地址中最多使用一次 `::`，否则无法确定省略位置的长度。

`2001:db8::/32` 和前面的 `192.0.2.0/24` 是文档示例范围，不用于说明当前设备的真实地址，也不应拿来测试互联网连接。

IPv6 地址还要看用途：

| 地址或范围 | 可以怎样理解 |
|---|---|
| `::1` | IPv6 本机回环地址，类似常用 IPv4 回环地址 `127.0.0.1` |
| `fe80::/10` 链路本地范围 | 只用于当前链路，路由器不把它作为普通地址转发到其他链路；看到它不代表已有 IPv6 互联网连接 |
| `fc00::/7` 唯一本地地址范围 | 用于本地网络互联，常见本地生成地址以 `fd` 开头；通常不在公共互联网路由 |
| 运营商或组织分配的全局单播地址 | 可用于全球寻址；是否真正可达，还取决于路由与安全策略 |

斜杠后面的数字表示网络前缀长度，可以先理解为“前多少个二进制位用于标识这段地址范围”，不是端口号。

一个接口可以同时拥有链路本地、全局地址，或临时地址；“一台设备只有一个 IP”不是普遍规则。[IPv6 地址架构](https://www.rfc-editor.org/rfc/rfc4291)、[唯一本地地址说明](https://www.rfc-editor.org/rfc/rfc4193)

## 四、为什么 IPv4 经常要共用公网地址

NAT = **Network Address Translation，网络地址转换**，通常读作“纳特”，也可逐字母读 N-A-T。

家庭路由器常见做法是同时转换地址和端口：让多台私有地址设备通过一个公网 IPv4 地址上网，并用转换记录区分回来的数据应交给谁。

```text
电脑 192.168.1.20 ─┐
手机 192.168.1.30 ─┼→ 家庭路由器做转换 → 公网出口 → 网站
平板 192.168.1.40 ─┘
```

这像一栋楼对外共用收发室地址，再由收发室分发给不同住户。若运营商还在上层让多个家庭共用地址，会形成额外的转换层，详见 [[防火墙与端口对外开放#CGNAT 为什么会让端口转发失效]]。

IPv6 的地址空间更大，可以给家庭分配一段地址，再由设备使用各自的全局地址。通常不需要仅为了节省地址而使用上述共享方式，但仍要经过路由器，不是设备绕过路由器直接上网。

不要把它理解成“IPv4 必须使用 NAT、IPv6 绝对不能进行地址转换”。IPv4 可以直接使用公网地址；IPv6 与 IPv4 互通等场景也存在转换机制。

### 有全局 IPv6 地址，别人就能访问我的电脑吗

不一定。通常仍需要同时满足：

1. 对方有可用的 IPv6 通信路径，或者存在适当的中间接入服务。
2. 运营商、路由器等允许流量到达。
3. 路由器和电脑的 IPv6 防火墙允许相应入站流量。
4. 本机服务在正确的 IPv6 地址和端口上监听。
5. 应用身份验证与权限允许访问。

因此，**不需要传统 IPv4 端口转发，不等于不需要防火墙；NAT 也不等于完整安全策略**。家庭 IPv6 网络同样需要控制外部主动发起的连接。[住宅 IPv6 网络安全建议](https://www.rfc-editor.org/rfc/rfc6092)

## 五、IPv4 与 IPv6 怎样共存

### 双栈：同一设备同时支持两种协议

Dual Stack（双栈）指同时实现 IPv4 和 IPv6。设备可能同时拥有两种地址；同一根网线或同一个无线网络也可以承载两种协议，不需要为它们各买一条线路。

双栈不是“每次访问都把两种地址的速度相加”，而是让应用具备选择合适通信方式的条件。[双栈与过渡机制](https://www.rfc-editor.org/rfc/rfc4213)

### 域名可以同时给出两种地址

DNS = **Domain Name System，域名系统**，逐字母读 D-N-S，常用于根据域名查询地址。

```text
example.com 的 A 记录    → IPv4 地址
example.com 的 AAAA 记录 → IPv6 地址
```

A 记录读字母 A，AAAA 常称“四 A 记录”。应用获得候选地址后，还要尝试建立连接。发布 AAAA 记录本身不会给服务器开通 IPv6，也不会自动配置路由与防火墙。

支持 Happy Eyeballs（用于改善连接建立体验的算法）的客户端可以交错或并行尝试候选连接，减少某一种地址路径异常造成的等待；实际选择还受应用实现和策略影响，不能简单说“有 IPv6 就永远只用 IPv6”。[IPv6 的 DNS 记录](https://www.rfc-editor.org/rfc/rfc3596)、[连接选择机制](https://www.rfc-editor.org/rfc/rfc8305)

查到了 IPv6 地址，也不代表当前网络能到达它；通过 IPv4 查询 DNS，也可以取得 IPv6 地址记录。DNS 查询的传输方式和查询结果的地址类型是两件事。

### 只支持一种协议时怎么办

仅支持 IPv4 的客户端与仅支持 IPv6 的服务器，不能仅凭双方各有一个地址就直接原生互通。需要端点增加相应协议支持，或使用合适的代理、网关、转换等中间机制。

例如 **NAT64** 是用于 IPv6 与 IPv4 地址及协议转换的一类机制，名字中的 64 指这里涉及版本 6 与版本 4，不是“64 位地址”。它需要实际部署和配置，不是系统看到不同地址就必然自动完成。[NAT64 规范](https://www.rfc-editor.org/rfc/rfc6146)

## 六、IPv6 是否更快、更安全

### 网速：不能只看版本号

实际速度取决于带宽、网络拥塞、路由、服务器位置、服务商接入和应用等。某个网站走 IPv6 可能更好，也可能更差或根本不可达；IPv6 不会自动把宽带套餐速度翻倍。

### 安全：两种都需要防护

使用 IPv6 不会让所有数据自动加密，也不会自动隐藏身份。安全传输仍需要 TLS（Transport Layer Security，传输层安全协议，逐字母读 T-L-S）等机制，应用仍需认证、授权与更新。

IPv4 与 IPv6 的防火墙、监听地址和代理接管情况应分别确认：只配置好一边，不能保证另一边也遵守相同的访问边界。详见 [[TLS与数字证书]]、[[系统代理、VPN与端口]] 和 [[防火墙与端口对外开放]]。

## 七、除了地址更长，还改了什么

初学可以先了解这些方向，不必一次学完所有细节：

- **数据包格式调整**：IPv6 有固定 40 字节的基本首部，额外信息可放入扩展首部；“固定基本首部”不表示整个数据包只有 40 字节。
- **自动配置机制**：SLAAC = Stateless Address Autoconfiguration，无状态地址自动配置，常读作“斯莱克”，可让主机结合路由器通告等信息配置地址；并不意味着不需要网络设备和运营商配合。
- **多播取代广播的相应用途**：IPv6 没有 IPv4 式的广播地址，相关功能通过多播等机制完成。多播可以先理解为发给特定组，而不是任意所有设备。

这些改进不是“所有场景必然更快”的承诺。[IPv6 规范](https://www.rfc-editor.org/rfc/rfc8200)、[无状态地址自动配置](https://www.rfc-editor.org/rfc/rfc4862)

## 八、对你实际使用电脑有什么影响

- 日常访问域名时，操作系统、应用和网络通常共同处理地址选择，你不必手工记住完整 IPv6 地址。
- 看到 IPv4 和 IPv6 地址同时存在，是正常的双栈现象；多个 IPv6 地址也不一定是异常。
- 只有 `fe80` 开头的链路本地地址，不能据此确认已开通 IPv6 上网。
- 建网站、远程访问或配置代理时，要分别检查两类地址的解析、路由、监听和防火墙，不是填一条地址就完成所有设置。
- IP 地址负责寻址，不代替端口；在网址中写 IPv6 字面地址和端口时，通常用方括号分隔，例如文档示意 `http://[2001:db8::10]:8080/`，其中 `8080` 才是端口。该地址不是可访问的演示网站。

想先观察自己的配置，可以在 Windows 终端运行只读命令 `ipconfig`，查看当前网卡的 IPv4、IPv6 和网关信息。命令显示的信息不能单独证明外网连通；若要公开截图，应先遮住真实地址等不必要的网络信息。

本次只整理知识笔记，没有更改电脑或路由器设置、关闭协议、开放端口，也没有测试你的实际网络。
